# ip2location.io-geolocation-gating
A quickstart repository to using ip2location.io for IP geolocation gating in online studies. For more details please see https://doi.org/10.31234/osf.io/r69hk_v2.

The code in this repository and the quickstart guide was created as a way for users to quickly understand how to implement post-hoc IP geolocation gating; i.e., to drop participants after a study has commenced and data collection is complete. This method, while useful, should not be your first port of call - it should be a priori IP geolocation gating. To find out how you might do that, please see Dr. Oriane Georgeac’s ip2location.io R package and preprint, linked above.
